# hiteshbandhu/tap

Homebrew tap for [hallmonitor](https://github.com/hiteshbandhu/hallmonitor) and
[zappp](https://github.com/hiteshbandhu/zappp).

```bash
brew install hiteshbandhu/tap/hallmonitor          # terminal board (macOS, Linux)
brew install --cask hiteshbandhu/tap/hallmonitor-app  # menu bar + notch app (macOS 14+)
brew install --cask hiteshbandhu/tap/zappp         # on-device dictation (Apple Silicon, macOS 14+)
```
